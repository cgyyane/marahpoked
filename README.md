# Mara.Hpoked — sitio web

HTML, CSS y JS puros. No necesita instalación.

## Publicar en GitHub Pages
1. Creá un repositorio nuevo en GitHub (por ejemplo `mara-hpoked`).
2. Subí **todo el contenido de esta carpeta** (index.html, css, js, img, video, .nojekyll) a la raíz.
3. En el repo: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
4. En 1 o 2 minutos queda en `https://TU-USUARIO.github.io/mara-hpoked/`.

## Después de publicar
- En `index.html`, reemplazá `content="img/og.jpg"` (og:image) por la URL completa, por ejemplo `https://TU-USUARIO.github.io/mara-hpoked/img/og.jpg`, y agregá `<meta property="og:url" content="...">`.
- El formulario de turnos usa el link `/viewform` del Google Form. Verificá que el formulario esté publicado y acepte respuestas.
- El formulario de contacto abre WhatsApp o el mail con el mensaje armado (no usa servidor).

## Textos a confirmar con Mara
Preguntas frecuentes, bio, bloque de gift card y frases como "materiales descartables".
